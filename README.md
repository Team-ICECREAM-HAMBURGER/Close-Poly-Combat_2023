복잡한 미로를 탐색하며 장애물에 숨겨진 목표물을 신속하게 제거해야 하는 ‘근접 전투(CQC)’ 훈련장을 재현한 FPS 게임입니다. 

전술적 판단과 정확한 사격이 요구되는 게임플레이를 통해 긴장감 넘치는 전투 경험을 제공합니다. 

새로운 장르 개발을 통해 역량 스펙트럼을 확장하고, FPS 메커니즘에 대한 연구를 심화하기 위해 기획된 R&D 목적으로 기획되었습니다.
